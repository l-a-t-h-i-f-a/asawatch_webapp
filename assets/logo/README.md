# Logo Folder

Letakkan file logo AsaWatch di sini.

## File yang dibutuhkan:

- `logo2.jpeg` - Logo utama (sudah ada dari Flutter app)
- `favicon.ico` - Favicon untuk browser (16x16 atau 32x32)
- `logo-192.png` - Logo untuk PWA icon (192x192)
- `logo-512.png` - Logo untuk PWA icon (512x512)

## Cara membuat PWA icons:

1. Buka `logo2.jpeg` di image editor
2. Resize ke 192x192 dan 512x512
3. Save sebagai PNG
4. Pastikan background transparan atau sesuai tema

## Generate favicon:

Gunakan online tool seperti:
- https://favicon.io/
- https://realfavicongenerator.net/

Upload `logo2.jpeg` dan download hasilnya ke folder ini.
